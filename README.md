# indus-invoice-bot

Quotes and invoices as PDFs. Payment is recorded by hand; this bot does not charge a card.

This bot comes from the INDUS Ops monorepo (https://github.com/mafzalkalwardev/indus-ops) and depends on indus-bot-core (https://github.com/mafzalkalwardev/indus-bot-core). Install and deploy are done from the monorepo.
